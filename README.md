# 考研工作台 · KaoyanWorkbench

2028 考研（河南大学 085410 人工智能 · 专硕）脱产 14 个月的手机端工作台。
所有内容都从你的 `2028考研_河南大学人工智能_脱产14个月作战计划.xlsx` 平移过来，
不是通用模板。

## 运行要求

| 项目 | 要求 |
| --- | --- |
| Xcode | **16.0 或更新**（工程用了 Xcode 16 的「同步文件夹」格式） |
| iOS | 17.0+ |
| 设备 | iPhone（模拟器也能跑） |
| 账号 | 免费 Apple ID 即可装到自己手机上（7 天有效期，需重签） |

## 三步跑起来

1. 把整个 `kaoyan-workbench-ios` 文件夹拷到 Mac 上。
2. 双击 `KaoyanWorkbench.xcodeproj`。
3. 选中 `KaoyanWorkbench` target → **Signing & Capabilities** → Team 选你自己的 Apple ID；
   然后顶部选你的 iPhone，按 `⌘R`。

> 第一次装到真机会提示「不受信任的开发者」：iPhone 设置 → 通用 → VPN与设备管理 → 信任。

如果在 Xcode 里提示 Bundle Identifier 冲突，把
`PRODUCT_BUNDLE_IDENTIFIER` 从 `com.kaoyan.workbench` 改成 `com.你的名字.kaoyanworkbench`。

## 五个页面

### 今日
- **倒计时**：距 2027-12-18 初试天数、已坚持天数、连续打卡、累计专注时长
- **当前阶段**：自动判断你处在「地基期 / 一轮期 / 强化期 / 冲刺期 / 考前」，
  并显示本月该推进的数学、408、英语、政治内容 + 本月里程碑
- **今日课表**：复刻「03 每日课表」的 9 个时间段，逐项打勾，自动累计学习时长；
  周日自动切换成休息版课表
- 额外补记时长、今日复盘（三行）、本周柱状图

### 计划
- **逐月路线**：14 个月 × 四个科目的完整内容，当前月高亮
- **关键节点**：12 个节点（报名、确认、打印准考证、初试、复试…），显示还有几天
- **目标分数**：四科目标/冲刺/底线分数条 + 报考信息 + 研招办电话

### 错题本
复刻你表里的核心机制：**当天录入 → 当日回炉① → 第 7 天回炉② → 两次都过才算掌握**。
- 到期未回炉的题会自动进入提醒队列
- 每题记「错误类型」和「正确思路（一句话）」

### 进度
「04 进度追踪」的 37 个进度项全部预置，按科目/模块折叠，
自动算各科完成率和总体完成度；顶部单独列出「本月该推进」的项。

### 我的
- **健康运动**（你新增的模块）：运动类型/时长、散步、睡眠、饮水，
  本周运动天数与平均睡眠、健康分、历史记录、脱产期间的身体底线提醒
- **预算**：2 万元弹药看板，实时余额、月均可动用、分类支出、资料清单
- 通用待办、复盘历史、完整备份与恢复、清空数据

### 学习周报
从「今日 → 本周专注」或「我的 → 学习周报」进入。

- **本周实际 vs 计划**：完成率环 + 小时数，按天累计的计划（9.5 小时基准）
- **与上周同期比**：只比「已过完的天数」，避免半周比整周的错觉
- **每日柱状图**：虚线是当天计划基准，柱子达标变绿；未来日子显示为占位
- **时间花在哪**：数学 / 408 / 英语 / 错题复盘 / 额外补记的时长与占比
- **本周明细**：达标天数、补记时长、写复盘天数、连续打卡
- **自动评语**：按完成率给一句不带情绪的提醒
- 可以左右翻看历史周

## 数据备份与恢复

数据只在本机，而免费签名的 App 7 天要重签一次——所以备份是必需品，不是可选项。

- **导出完整备份**：生成一个 `.json` 文件，用系统文件导出器存到「文件」App 或网盘。
  内容包含打卡记录、错题、进度项、预算、待办、设置，**以及资料库附件的二进制**（base64）
- **从备份恢复**：选一个备份文件 → 弹出备份时间与内容摘要 → 二次确认后**覆盖**本机数据
- 恢复流程：先落地附件文件 → 清掉备份里没有的旧附件 → 覆盖业务数据 → 重建通知排程
- 「我的 → 数据」会显示上次备份是几天前；没备份过会显示橙色提醒
- 纯 JSON 格式，可以用任何文本编辑器打开检查

## 错题回炉提醒

完成「回炉①」后，App 会用**本地通知**在第 7 天提醒你回炉②。

- 开关与时间在「我的 → 错题回炉提醒」，默认关，时间默认 09:00（可调 06:00–22:00）
- 首次开启时请求系统通知授权；被拒绝会显示「去设置」入口
- 完成回炉②或删除错题，对应通知自动取消
- 每次启动、以及任何错题状态变化后都会重建排程，保证通知与数据一致
- 最多同时排 60 条（iOS 单 App 上限 64 条）
- 用 `UNUserNotificationCenter` 本地通知，**不需要服务器，也不需要付费开发者账号**
## 资料库（PDF / 图片 / 文字）

学完的东西不只是一个勾。资料库让你把**实际学习内容**存进 App：

- **导入文件**：PDF、图片、文本（文件选择器，拷进 App 沙盒，不联网）
- **相册选图**：拍课本、拍手写笔记
- **文字笔记**：直接写，带标题和备注
- **双重归属**：每条资料可以同时挂到「某一天」和「某个章节（进度项）」
  - 挂到日期 → 出现在「今日」页的「今天学过什么」
  - 挂到章节 → 在「进度」页该章节右侧的 📎 里按章节翻看
- 预览用系统 QuickLook（PDF / 文本）或原图显示（图片），可分享、可删除
- 入口：「我的」→「资料库」；或「今日」页右上角 +；或「进度」页每章节的 📎

数据同样只存本机 `Documents/Materials`，随 iCloud 备份。

## App 图标

文件：`KaoyanWorkbench/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`
（1024×1024，RGB 无 alpha，符合 App Store 要求）

图标由 `tools/make_icon.py` 用 Pillow 纯几何绘制生成 —— 蓝紫渐变底 + 白色学士帽 + 对勾徽章。
不依赖任何字体，所以任何环境都能复现。改配色或形状后重新生成：

```bash
python tools/make_icon.py
```

## 云端编译（不需要本地有 Mac）

工程已带 `.github/workflows/ios-build.yml`：推到 GitHub 后，
每次 push 都会在 **macOS 15 + Xcode 16** 的云端机器上跑一次 `xcodebuild build`
（模拟器目标、不签名），把编译器能看见的错误全部摊开。

会做四件事：

1. 打印 Xcode / Swift 版本
2. `plutil -lint` 校验 `project.pbxproj` 格式
3. `xcodebuild -list` 确认 scheme 能被识别
4. `xcodebuild build` 真编译，失败时把 `error:` 行和第一处上下文单独打印，
   并把完整 `build.log` 作为工件上传

看结果的地方：仓库 → **Actions** 标签页 → 点最新一次运行 →
失败时展开「提取编译错误」，或用「xcodebuild-log」工件下载完整日志。
